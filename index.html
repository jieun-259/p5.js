보증금·월세·통학 거리·면적·옵션 조건을 가중치에 따라 실시간으로 점수화하고, p5.js 인터랙티브 레이더 차트와 캠퍼스 지도로 한눈에 비교하는 팀 프로젝트 도구입니다.

프로젝트 제작진

최지원, 김세정, 김수현, 배지은

최초 실행 시 바로 비교해 볼 수 있도록 샘플 매물 3개와 샘플 방문 일정이 기본 제공되며, 모든 변경 내용은 브라우저에 자동 저장됩니다.

간단한 사용 방법

  1. 01. 매물 등록 & 사진 업로드 보증금·월세·관리비·거리·면적·옵션과 현장 사진을 압축해 등록합니다.
  2. 02. 가중치 조절 & p5.js 비교 중요한 항목의 슬라이더를 조절하고, 지도 핀을 드래그해 실시간 순위를 확인합니다.
  3. 03. 현장 방문 체크리스트 & 별점 수압·채광·곰팡이·방음·옵션 상태를 기록하고 별점과 메모를 남깁니다.
  4. 04. 방문 일정 캘린더 & 결과 저장 달력에서 방 보러 갈 일정을 관리하고 최종 비교표를 PNG·리포트 파일로 저장합니다.

사용 기술 및 구현 특징

  • HTML5 / CSS3 / Vanilla JavaScript (ES6+) — 별도 프레임워크 없이 GitHub Pages에 바로 배포 가능한 정적 모듈 구조
  • p5.js (CDN v1.9.4) — 4축 레이더 차트, 점수 막대 그래프, 드래그 가능한 캠퍼스 지도 핀, fullscreen() 및 windowResized() 대응
  • LocalStorage API — 매물, 압축 사진, 가중치, 체크리스트, 별점, 방문 일정 자동 저장 및 복원
  • 결과물 내보내기 — p5.js saveCanvas()를 활용한 고해상도 PNG 요약 리포트 및 텍스트(.txt) 요약표 다운로드
